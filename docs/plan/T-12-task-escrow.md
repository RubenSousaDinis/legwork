# T-12 — TaskEscrow: the money path, in two PRs

## 1. Context
`TaskEscrow` holds every task's USDC from `post` to `Released`/`Refunded`/`Resolved`. The Task API (relayer key) posts on behalf of an x402 payer and relays claims and submissions for workers; the CLI worker and a future self-custodial path use the direct `claim`/`submit`; the buyer (or the relayer for it) approves or disputes; anyone can `autoRelease` or `expire`; the owner arbitrates disputes. On release the contract calls `Reputation.feedback` (worker side, keyed by nullifier) and `AbuseMark.outcome` (agent side, ERC-8004). The subgraph (lane C), the dashboard (lane D), `Deploy.s.sol`/`Seed.s.sol` (T-14) and the e2e harness (T-36) consume the events and views named below. **Two PRs:** `(1/2)` posting, claiming, releasing a claim, submitting, expiry, lazy expiry, cooldown, pause, allowlist; `(2/2)` approve, dispute, autoRelease, resolve, fee math, `_release` with the two hooks.

> **02-architecture — TaskEscrow** "The fee is on top: the agent pays `amount × 1.15` through x402; the escrow locks `amount + fee`; the worker receives 100% of `amount`. Demo task: agent pays 3.45, escrow locks 3.45, worker receives 3.00, treasury 0.45. · `post(…)` — called by the operator from a pre-funded float **after** x402 `/verify` and screening and **before** `/settle`. `buyer` is the x402 payer address (cryptographically bound into the signed EIP-3009 authorization, so it cannot be swapped). `disputeWindow` is a parameter: production default [86 400 s], filmed tasks 120 s so the auto-release path is what judges see. Per-task cap `MAX_TASK_AMOUNT`; `maxOpenTasksPerBuyer` (5 in v0) so the bound is onchain, not policy. · `claimFor(taskId, worker)` / `submitFor(taskId, worker, proofHash)` — `onlyRelayer`; `isWorker(worker)` required; one open claim per worker; a **seeded** worker may only claim a task whose `buyer` is the operator (seeded completions feed the preflight medians; no seeded address can ever claim a task a real buyer paid for). Direct `claim()` / `submit()` from `msg.sender` are retained for the CLI worker and a future self-custodial path. · **Lazy expiry:** `claimFor` succeeds if the task is OPEN or `block.timestamp > claimedAt + claimTTL`, overwriting the stale claimant and emitting `ClaimExpired`. No keeper exists in a hackathon; nothing can strand a task. An expired claimant enters a short cooldown (one mapping, ~15 min) so a single worker cannot deny a task by claiming and vanishing in a loop. · `approve(taskId)` by `buyer` or by the relayer on the buyer's behalf; `dispute(taskId)` likewise, allowed while `block.timestamp < submittedAt + disputeWindow`; `autoRelease(taskId)` by anyone after that; `resolve(taskId, toBuyer)` by the operator key after a dispute — **zero fee on any `resolve` outcome** (to worker: worker gets `amount`, buyer gets the fee back; to buyer: buyer gets `amount + fee`). "We do not earn on a task we arbitrate." · `expire(taskId)` — refunds `amount + fee` to `buyer` if never claimed or never submitted. · `release` → `USDC.transfer(worker, amount)` + `USDC.transfer(treasury, fee)`; checks-effects-interactions; USDC has no transfer hooks, so there is no callback surface. · `pause()` (Ownable) affects `post` and `claim*` only — never `submit`, `release`, `autoRelease` or `expire`, so a stop can never trap a worker's earned funds. The asymmetry is the design choice; say it. · Every transition emits an event for the subgraph."

> **02-architecture — security table** "**FIX** Agent pays and gets nothing — `buyer` = x402 payer in `post`; `expire` and `resolve(toBuyer)` pay `buyer` — `test_Expire_RefundsBuyer`, `test_Resolve_ToBuyer_NoFee`" · "**FIX** Splitting the loss: an injected agent posts a hundred tasks — `maxOpenTasksPerBuyer` onchain — `test_Post_RevertsOverOpenCap`" · "**FIX** Seeded workers mint "verified humans" — seeded workers can only claim operator-funded tasks — `test_Seeded_CannotClaimExternalTask`" · "**FIX** Junk proof, nobody watching the dispute window — `disputeWindow` per task — `test_AutoRelease_AfterWindow`, `test_Dispute_InsideWindow`" · "**FIX** Claim-and-vanish, stranded task — Lazy expiry inside `claimFor`; cooldown after an expired claim — `test_Claim_LazyExpiry`, `test_Claim_CooldownAfterExpiry`" · "**FIX** Operator key compromise — `pause` on `post`/`claim` only — `test_Pause_NeverBlocksRelease`" · "Not a row: reentrancy. USDC has no transfer hooks; a plain-ERC20 escrow has no callback surface. Do not write a paragraph about it; the named tests are the answer."

The frozen surface, verbatim from **T-01 §2 `ITaskEscrow`** (read `contracts/src/interfaces/ITaskEscrow.sol` before coding; the merged file wins over this quote):
> `enum TaskState { None, Open, Claimed, Submitted, Released, Refunded, Disputed, Resolved }` · `struct PostParams { uint8 taskType; bytes32 specHash; uint96 amount; address buyer; uint256 buyerAgentId; string area; uint32 claimTTL; uint32 submitTTL; uint32 disputeWindow; }` · `struct Task { uint8 taskType; bytes32 specHash; uint96 amount; uint96 fee; address buyer; uint256 buyerAgentId; string area; address worker; TaskState state; uint64 postedAt; uint64 claimedAt; uint64 submittedAt; uint32 claimTTL; uint32 submitTTL; uint32 disputeWindow; bytes32 proofHash; }` · `post(PostParams p) → uint256 taskId` — `onlyRelayer`, `whenNotPaused`. Pulls `p.amount + fee` USDC from `msg.sender` (the relayer float) with `safeTransferFrom`. Requires `p.amount ≤ MAX_TASK_AMOUNT`, `p.amount ≥ 1_000_000`, `openTasksOf(p.buyer) < maxOpenTasksPerBuyer` (else `OverOpenCap`), `p.taskType ∈ {1,2,4,8}`. Emits `TaskPosted`. · `postAsBuyer(PostParams p) → uint256` — `whenNotPaused`; requires `p.buyer == msg.sender`; pulls from `msg.sender`; otherwise identical. · `claimFor(uint256 taskId, address worker)` — `onlyRelayer`, `whenNotPaused`. `claim(uint256 taskId)` — `worker = msg.sender`, `whenNotPaused`. Rules for both: `registry.isWorker(worker)`; worker has no other open claim (`activeClaimOf[worker] == 0`); `block.timestamp ≥ cooldownUntil[worker]` (else `InCooldown`); if `registry.isSeeded(worker)` then `allowlistedBuyer[task.buyer]` must be true (else `SeededCannotClaimExternal`); state is `Open`, **or** `Claimed` with `block.timestamp > claimedAt + claimTTL` — in that case emit `ClaimExpired(taskId, staleWorker)`, set `cooldownUntil[staleWorker] = block.timestamp + CLAIM_COOLDOWN`, clear the stale claimant's active claim, then proceed (lazy expiry; no keeper). Sets `claimedAt`, `worker`; emits `TaskClaimed`. · `releaseClaimFor(uint256 taskId, address worker)` — `onlyRelayer`. `releaseClaim(uint256 taskId)` — `msg.sender`. `Claimed` by that worker → `Open`; no cooldown. Emits `ClaimReleased`. · `submitFor(uint256 taskId, address worker, bytes32 proofHash)` — `onlyRelayer`. `submit(uint256 taskId, bytes32 proofHash)` — `msg.sender`. Requires `Claimed` by that worker and `block.timestamp ≤ claimedAt + submitTTL` (else `SubmitWindowClosed`). → `Submitted`, `submittedAt`, `proofHash`; emits `TaskSubmitted`. **Never gated by pause.** · `approve(uint256 taskId)` — caller is `task.buyer` **or** the relayer. Requires `Submitted`. → `_release`. · `dispute(uint256 taskId)` — caller is `task.buyer` or the relayer. Requires `Submitted` and `block.timestamp < submittedAt + disputeWindow`. → `Disputed`; emits `TaskDisputed`. · `autoRelease(uint256 taskId)` — anyone. Requires `Submitted` and `block.timestamp ≥ submittedAt + disputeWindow`. → `_release`. **Never gated by pause.** · `resolve(uint256 taskId, bool toBuyer)` — `onlyOwner`. Requires `Disputed`. `toBuyer = true`: transfer `amount + fee` to buyer. `toBuyer = false`: transfer `amount` to worker **and** `fee` back to buyer (zero fee on any resolve). Feedback outcome `ResolvedToBuyer` / `ResolvedToWorker`. → `Resolved`; emits `TaskResolved(taskId, toBuyer)`. · `expire(uint256 taskId)` — anyone. Requires (`Open` and `block.timestamp > postedAt + claimTTL`) **or** (`Claimed` and `block.timestamp > claimedAt + submitTTL`). Refunds `amount + fee` to `buyer`. → `Refunded`; emits `TaskRefunded(taskId, buyer, amount + fee)`. **Never gated by pause.** · `_release` (internal): checks-effects-interactions — set `Released`, clear the worker's active claim, then `USDC.safeTransfer(worker, amount)`, `USDC.safeTransfer(treasury, fee)`, `reputation.feedback(registry.nullifierOf(worker), raterKey, OUTCOME_PAID, taskId)`, and if `buyerAgentId != 0` `abuseMark.outcome(buyerAgentId, taskId, OUTCOME_PAID)`. Emits `TaskReleased(taskId, worker, amount, fee)`. `raterKey = buyerAgentId != 0 ? bytes32(buyerAgentId) : bytes32(uint256(uint160(buyer)))`. · `pause()` / `unpause()` — `onlyOwner`; gates **only** `post`, `postAsBuyer`, `claimFor`, `claim`. · `setAllowlistedBuyer(address buyer, bool allowed)` — `onlyOwner`; emits `BuyerAllowlisted(buyer, allowed)`. · Constants/config: `FEE_BPS = 1500`, `MAX_TASK_AMOUNT = 10_000_000` (10 USDC, immutable), `maxOpenTasksPerBuyer = 5`, `CLAIM_COOLDOWN = 900`. `fee = amount * FEE_BPS / 10_000` (3.00 → 0.45). · Views: `getTask(uint256) → Task`, `openTasksOf(address) → uint256`, `activeClaimOf(address) → uint256`, `cooldownUntil(address) → uint256`, `allowlistedBuyer(address) → bool`, `taskCount() → uint256`, `usdc()`, `treasury()`, `relayer()`, `registry()`, `reputation()`, `abuseMark()`. · Events: `TaskPosted(uint256 indexed taskId, address indexed buyer, uint256 buyerAgentId, uint8 taskType, bytes32 specHash, uint96 amount, uint96 fee, string area, uint32 claimTTL, uint32 submitTTL, uint32 disputeWindow)` · `TaskClaimed(uint256 indexed taskId, address indexed worker)` · `ClaimReleased(uint256 indexed taskId, address indexed worker)` · `ClaimExpired(uint256 indexed taskId, address indexed staleWorker)` · `TaskSubmitted(uint256 indexed taskId, address indexed worker, bytes32 proofHash)` · `TaskReleased(uint256 indexed taskId, address indexed worker, uint96 amount, uint96 fee)` · `TaskDisputed(uint256 indexed taskId)` · `TaskResolved(uint256 indexed taskId, bool toBuyer)` · `TaskRefunded(uint256 indexed taskId, address indexed buyer, uint96 total)` · `BuyerAllowlisted(address indexed buyer, bool allowed)` · OZ `Paused`/`Unpaused`.

Outcome codes (T-01 §2 `IReputation`, shared with AbuseMark): `1 = Paid`, `2 = ResolvedToWorker`, `3 = ResolvedToBuyer`. Custom errors beyond T-01 that `FakeChain` (T-07) and the API decode, from `tasks/LEAD-NOTES.md`: `NotRelayer`, `NotBuyer`, `NotBuyerOrRelayer`, `NotWorker`, `HasActiveClaim`, `AlreadyClaimed`, `NotClaimant`, `BadState`, `BadTaskType`, `AmountOutOfRange`, `DisputeWindowClosed`, `DisputeWindowOpen`, `NotExpired`, plus OpenZeppelin's `EnforcedPause` and `OwnableUnauthorizedAccount`.

## 2. Exact scope
- `contracts/src/TaskEscrow.sol`: `contract TaskEscrow is ITaskEscrow, Ownable, Pausable` (OpenZeppelin 5), `using SafeERC20 for IERC20`. Constructor `(address initialOwner, address usdc_, address treasury_, address relayer_, address registry_, address reputation_, address abuseMark_)`. Store each address with the **exact type the merged interface's getter returns** (`usdc()`, `treasury()`, `relayer()`, `registry()`, `reputation()`, `abuseMark()` — if they return `address`, store `address` and cast at the call site, e.g. `IERC20(usdc).safeTransfer(...)`). `usdc` and `registry` are `immutable`; there is **no** setter for relayer or treasury in v0 (constructor only; see §13).
- Storage: `mapping(uint256 => Task) private _tasks`, `uint256 public taskCount`, `mapping(address => uint256) public openTasksOf`, `mapping(address => uint256) public activeClaimOf`, `mapping(address => uint256) public cooldownUntil`, `mapping(address => bool) public allowlistedBuyer`. Constants: `uint256 public constant FEE_BPS = 1500`, `uint96 public constant MAX_TASK_AMOUNT = 10_000_000`, `uint96 public constant MIN_TASK_AMOUNT = 1_000_000`, `uint256 public constant CLAIM_COOLDOWN = 900`, `uint256 public maxOpenTasksPerBuyer = 5` (no setter in v0). Outcome codes `uint8 internal constant OUTCOME_PAID = 1`, `OUTCOME_RESOLVED_TO_WORKER = 2`, `OUTCOME_RESOLVED_TO_BUYER = 3` — if T-01a ships a library with these, import it instead of redeclaring. No arrays, no loops, no assembly.
- `openTasksOf[buyer]` counts tasks in `Open`, `Claimed`, `Submitted`, `Disputed`; it increments in `_post` and decrements exactly once when a task reaches `Released`, `Refunded` or `Resolved`.
- `_post(PostParams calldata p, address payer)` shared by `post` (`onlyRelayer`, `whenNotPaused`, `payer = msg.sender`) and `postAsBuyer` (`whenNotPaused`; `p.buyer != msg.sender` → `NotBuyer`; `payer = msg.sender`). Check order: (1) `p.taskType` not in `{1,2,4,8}` → `BadTaskType`; (2) `p.amount < MIN_TASK_AMOUNT || p.amount > MAX_TASK_AMOUNT` → `AmountOutOfRange`; (3) `openTasksOf[p.buyer] >= maxOpenTasksPerBuyer` → `OverOpenCap`. No TTL validation onchain (the API validates). Effects: `taskId = ++taskCount`; `fee = uint96(uint256(p.amount) * FEE_BPS / 10_000)`; write the `Task` with `state = Open`, `postedAt = uint64(block.timestamp)`, `worker = address(0)`; `openTasksOf[p.buyer]++`; emit `TaskPosted`. Interaction last: `safeTransferFrom(payer, address(this), p.amount + fee)`.
- `_claim(uint256 taskId, address worker)` shared by `claimFor` (`onlyRelayer`, `whenNotPaused`) and `claim` (`whenNotPaused`, `worker = msg.sender`). Check order — **exactly this**: (1) `!registry.isWorker(worker)` → `NotWorker`; (2) `activeClaimOf[worker] != 0` → `HasActiveClaim`; (3) `block.timestamp < cooldownUntil[worker]` → `InCooldown`; (4) `registry.isSeeded(worker) && !allowlistedBuyer[t.buyer]` → `SeededCannotClaimExternal`; (5) state `Open` → proceed; state `Claimed` and `block.timestamp > t.claimedAt + t.claimTTL` → lazy expiry (`stale = t.worker`; `activeClaimOf[stale] = 0`; `cooldownUntil[stale] = block.timestamp + CLAIM_COOLDOWN`; emit `ClaimExpired(taskId, stale)`), proceed; state `Claimed` otherwise → `AlreadyClaimed`; any other state → `BadState`. Then `t.worker = worker; t.state = Claimed; t.claimedAt = uint64(block.timestamp); activeClaimOf[worker] = taskId`; emit `TaskClaimed(taskId, worker)`. An `Open` task past `postedAt + claimTTL` is still claimable; `expire` is the only path that retires it.
- `_releaseClaim(taskId, worker)` for `releaseClaimFor` (`onlyRelayer`) / `releaseClaim` (`msg.sender`): state not `Claimed` → `BadState`; `t.worker != worker` → `NotClaimant`; then `state = Open`, `worker = address(0)`, `claimedAt = 0`, `activeClaimOf[worker] = 0`, **no cooldown**; emit `ClaimReleased(taskId, worker)`. Not pause-gated.
- `_submit(taskId, worker, proofHash)` for `submitFor` (`onlyRelayer`) / `submit` (`msg.sender`): not `Claimed` → `BadState`; `t.worker != worker` → `NotClaimant`; `block.timestamp > t.claimedAt + t.submitTTL` → `SubmitWindowClosed`; then `state = Submitted`, `submittedAt`, `proofHash`; emit `TaskSubmitted`. `activeClaimOf[worker]` **stays set** until `_release`/`resolve` (T-01 literal; see §13). Not pause-gated.
- `expire(taskId)`: anyone; state not `Open`/`Claimed` → `BadState`; not (`Open && block.timestamp > postedAt + claimTTL`) and not (`Claimed && block.timestamp > claimedAt + submitTTL`) → `NotExpired`. Effects: `state = Refunded`; if `t.worker != address(0)` clear `activeClaimOf[t.worker]` (**no cooldown** — the only cooldown is lazy expiry); `openTasksOf[buyer]--`; emit `TaskRefunded(taskId, t.buyer, t.amount + t.fee)`. Interaction: `safeTransfer(t.buyer, t.amount + t.fee)`. Not pause-gated.
- `approve(taskId)`: `msg.sender != t.buyer && msg.sender != relayer` → `NotBuyerOrRelayer`; not `Submitted` → `BadState`; `_release(taskId)`. `dispute(taskId)`: same caller rule and state rule; `block.timestamp >= submittedAt + disputeWindow` → `DisputeWindowClosed`; `state = Disputed`; emit `TaskDisputed(taskId)`. `autoRelease(taskId)`: anyone; not `Submitted` → `BadState`; `block.timestamp < submittedAt + disputeWindow` → `DisputeWindowOpen`; `_release(taskId)`. None of the three is pause-gated.
- `resolve(taskId, toBuyer)`: `onlyOwner`; not `Disputed` → `BadState`. Effects: `state = Resolved`; `activeClaimOf[worker] = 0`; `openTasksOf[buyer]--`; emit `TaskResolved(taskId, toBuyer)`. Interactions: `toBuyer` → `safeTransfer(buyer, amount + fee)`; else `safeTransfer(worker, amount)` **and** `safeTransfer(buyer, fee)`; then `reputation.feedback(registry.nullifierOf(worker), raterKey, toBuyer ? OUTCOME_RESOLVED_TO_BUYER : OUTCOME_RESOLVED_TO_WORKER, taskId)`; if `buyerAgentId != 0`, `abuseMark.outcome(buyerAgentId, taskId, <same code>)`. The treasury receives nothing on either branch.
- `_release(taskId)`: effects `state = Released`, `activeClaimOf[worker] = 0`, `openTasksOf[buyer]--`, emit `TaskReleased(taskId, worker, amount, fee)`; interactions `safeTransfer(worker, amount)`, `safeTransfer(treasury, fee)`, `reputation.feedback(registry.nullifierOf(worker), raterKey, OUTCOME_PAID, taskId)`, and if `buyerAgentId != 0` `abuseMark.outcome(buyerAgentId, taskId, OUTCOME_PAID)`. `raterKey` exactly as T-01. In every function the order is **state writes → event → external calls**; T-01's placement of "Emits" in its prose is not an ordering requirement.
- `pause()`/`unpause()`: `onlyOwner`, OZ `_pause`/`_unpause`; `whenNotPaused` appears on exactly four functions: `post`, `postAsBuyer`, `claimFor`, `claim`. `setAllowlistedBuyer`: `onlyOwner`; emits `BuyerAllowlisted`. `onlyRelayer` modifier reverts `NotRelayer`. `getTask` returns the struct by value; the other views are the public mappings/vars with signatures matching the interface.
- NatSpec header: operator powers in v0 — disclosed: `resolve`, `pause`, `setAllowlistedBuyer`; the sentence "pause gates post and claim only — a stop can never trap a worker's earned funds"; the money line "agent pays 3.45, escrow locks 3.45, worker receives 3.00, fee 0.45". No reentrancy paragraph anywhere.
